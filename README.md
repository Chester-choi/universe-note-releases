# Universe Note 설치 파일

개인용 노션 스타일 기록·위키 맥 앱 **Universe Note** 의 설치 파일을 올리는 곳이에요.
(앱 코드는 비공개 저장소에 있고, 여기에는 설치 파일만 올라가요.)

## 받기

👉 **[최신 버전 받기](https://github.com/Chester-choi/universe-note-releases/releases/latest)**

내 맥의 칩에 맞는 파일을 받으세요. ( 메뉴 → "이 Mac에 관하여" → 칩)

| 칩 | 받을 파일 |
|---|---|
| Apple M1 / M2 / M3 / M4 … | `Universe-Note-<버전>-AppleSilicon.dmg` (또는 `.pkg`) |
| Intel | `Universe-Note-<버전>-Intel.dmg` (또는 `.pkg`) |

- `.dmg` — 열어서 Universe Note 를 Applications 폴더로 끌어다 놓기
- `.pkg` — 더블클릭해서 안내대로 설치

## 처음 열 때 경고가 뜨면

Apple 공증을 받지 않은 개인 앱이라 "확인할 수 없는 개발자" 경고가 떠요.
**시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"** 를 한 번 누르면 돼요.
