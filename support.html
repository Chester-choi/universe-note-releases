자주 묻는 질문

캘린더가 보이지 않아요.
시스템 설정 → 개인정보 보호 및 보안 → 캘린더(그리고 미리 알림)에서 우주 노트(Universe Note)를 켜 주세요. 구글 캘린더는 시스템 설정 → 인터넷 계정에서 캘린더를 켜야 보여요.

다른 Mac의 노트를 가져오고 싶어요.
처음 실행 화면에서 '☁️ iCloud에서 가져오기'를 누르거나, 설정 → iCloud 동기화를 켜 주세요. 두 Mac이 같은 Apple ID로 로그인되어 있어야 해요.

암호를 잊었어요.
로그인 화면의 '암호를 잊으셨나요?'를 누르고 Touch ID 또는 Mac 로그인 암호로 확인하면 새 암호를 정할 수 있어요.

예전 상태로 되돌리고 싶어요.
설정 → 백업 → '백업에서 되돌리기'에서 원하는 날짜의 백업을 고르세요. 바뀐 내용이 있으면 하루 한 번 자동으로 백업돼요.

데이터는 어디에 저장되나요?
내 Mac과 (동기화를 켜면) 내 iCloud에만 저장돼요. 자세한 내용은 개인정보처리방침을 봐 주세요.
